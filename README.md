# Baitap_Phantichtrucquan

Bài học và bài tập môn Phân tích trực quan.

- `code/` — notebook bài học, bài tập (`.ipynb`) và file Python
- `dataset/` — dữ liệu dùng trong các bài

Các notebook đọc dữ liệu bằng đường dẫn tương đối `../dataset/<tên file>`, nên hãy chạy notebook từ trong thư mục `code/`.
